# YardCraft · Павлодар

Просмотр предложений соседей: карточки голосования и страница результата содержат кнопки карты и 3D. Маршрут `?plan=<id>#preview` показывает сохранённые объекты и расчёт без замены локального черновика. Прогулка запускается с копией данных и запретом редактирования. Чтобы изменить такой вариант, пользователь явно выбирает «Создать свою копию».

Старт прогулки фиксирован относительно центра зоны: компактная площадка 40 × 36 м с четырьмя ближайшими домами и одной точкой появления. Для больших выбранных территорий добавляются облегчённые дальние ряды домов. Координаты объектов не сжимаются и не растягиваются. На карте размер моделей ограничен географическим масштабом и границей двора; при отдалении вместо моделей показываются маленькие точки; в прогулке размер натуральный. Проверка: `node scripts/check-yardcraft.mjs`.

Инструкция: кнопка в шапке сайта запускает 10 подсказок с подсветкой элементов, анимированными примерами и объяснением действия/результата. В прогулке есть отдельная кнопка с 9 шагами; при объяснении переноса временно выбирается существующая модель без изменения данных. Исходный режим и выбор восстанавливаются после закрытия. Дополнительные контекстные подсказки предусмотрены для голосования и результата. Клавиши ← → переключают шаги, Esc закрывает; анимации учитывают `prefers-reduced-motion`. Исходники: `public/guide.js`, `public/guide.css`.

Типовой двор в прогулке теперь окружён четырьмя пятиэтажными домами с подъездами, козырьками, ступенями и табличками. Между домами и центральной территорией проходят проезды с разметкой, бордюрами, тротуарами и переходами. Отмеченная территория остаётся грунтовой площадкой для расстановки объектов с исходными географическими координатами. Есть быстрые переходы к четырём домам, отображение окружения на мини-карте и препятствия на местах стен. Код окружения: `src/courtyard.js`.

Прогулка: кнопка «Прогуляться по двору» открывает Three.js-сцену в пределах отмеченного двора. WASD / стрелки — движение, Shift — быстрее, перетаскивание — обзор. На телефоне есть кнопки движения. В режиме редактирования доступны выбор модели, перенос кликом по земле, добавление из каталога, удаление и отмена до 30 правок. Изменения сразу сохраняются в черновике и синхронизируются с картой; для общей ссылки затем нужно сохранить новый вариант. Окружение схематичное, географические позиции объектов совпадают с планом, в прогулке используется натуральный размер моделей. Сборка после изменений исходника: `npm run build:walk`.

3D-объекты: девять собственных процедурных моделей GLB в `public/models`, отрисовка через официальный glTF-плагин 2ГИС. Камера смотрит сверху, масштаб моделей адаптируется к зуму для читаемости (не технический план в масштабе). Миниатюры SVG построены по той же геометрии. Пересборка: `node scripts/build-models.mjs`; проверка glTF: `node scripts/validate-models.mjs`. Нажатие по модели удаляет её и пересчитывает бюджет; при недоступности 3D есть резервные виды сверху.

Обновлённый интерфейс: вход без пароля, одна стартовая страница с картой, адресом и бюджетом рядом. Лендинг и отдельная настройка удалены. На Vercel подпись cookie демо-голосования использует `COOKIE_SECRET` либо `BLOB_READ_WRITE_TOKEN`; пароль для доступа больше не применяется.

Опубликовано: https://budget-dvora-pavlodar.vercel.app

На Vercel API работает через `api/handler.mjs`, варианты и голоса сохраняются отдельными объектами в приватном Vercel Blob. Нужны переменные `DGIS_KEY`, `DEMO_PASSWORD`, `BLOB_READ_WRITE_TOKEN`. Cookie входа подписана HMAC и действует семь дней. Повторный деплой: `vercel deploy --prod`. Проверены production-вход, чтение, создание варианта, сохранение и повторное чтение голоса, отображение карты с маркерами, добавление площадки и превышение на 280 000 ₸.

Запуск: `npm start`, затем http://127.0.0.1:4173. Node.js 22+, установка зависимостей не требуется.

Настройки читаются из `.env` (образец — `.env.example`). Пароль проверяется сервером, ключ MapGL передаётся клиенту после входа. Ключ браузерной карты виден посетителю по определению; настройте ограничения доменов в кабинете 2ГИС. Поиск адресов требует отдельного доступа ключа к Places API; при его отсутствии доступен ручной выбор на карте.

Пять экранов: главная, настройка, конструктор, голосование, результат. На карте можно выделить зону, ставить объекты внутри неё и удалять нажатием на маркер. Один объект соответствует указанной в каталоге единице или участку. Пример на 5 млн: 1 480 000 ₸; добавление площадки повышает стоимость до 5 280 000 ₸.

Варианты и голоса сохраняются сервером в `data/plans.json`. Черновик хранится в localStorage. Голосование демонстрационное: один голос на cookie браузера, без идентификации жителей. Удаление cookie позволяет проголосовать повторно. Пароль защищает демо, не заменяет полноценную авторизацию.

Ссылка на 127.0.0.1 открывается только на этом компьютере. Для соседей потребуется доступный сервер, HTTPS и соответствующие ограничения ключа 2ГИС. Для публичного запуска также нужны полноценная авторизация, ограничение запросов, резервное копирование и база данных. Текущий JSON-сервер рассчитан на один процесс демонстрации.

Выгрузка предложения: TXT с расчётом и координатами; PDF — через кнопку «Печать / PDF». Все цены демонстрационные и не являются сметой. Районы — приблизительные точки навигации, не административные границы.
